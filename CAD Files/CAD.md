## Instructions:

The brackets are a mix of Onshape (.step) and Inventor Part (.ipt) files. Inventor Part files can be opened in Onshape. Onshape files must be exported as a STEP file in order to be properly opened in Inventor. The brackets are named by their size (ex. 3x3 is roughly 3 inches by 3 inches). The actual size is slightly larger due to extra room being required past the screw holes. 

Acrylic Plate files are present in both ipt and DWG files. The DWG files can be used to upload for a laser cutter.

## Explanations:
4x4 Mariner Board:
This already has the insert mounts designed into the board for extra security and to reduce risk of fire hazards

## Radio Bracket:
Assembly file but works as a single part
A radio can be screwed into either side of the vertical piece of the radio
Each bracket can hold 2 RFD900 radios

## Pi Supports:
The Pi only supports 2 4N40 screws to secure it so these square supports are designed to be glued underneath the other corners to provide support and stability to the Pi

## Box Tray Top
The top pieces of the 3 story acrylic plates
Has 2 slightly different pieces in the one file. If going to print/laser cut make sure to include both pieces

## Box Tray Original
The original CAD model for the base layer tray
Preserves locations of key mounting and sensor screw holes

## Housing Box
An assembly file taken from Fusion of the plastic housing box

## Box Tray Assembly
Full assembly of housing box, acrylic plates, key sensors, and various bracket sizes
Not fully up to date
